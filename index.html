Gemini APIキーの設定・作成方法

本アプリの「写真読み取り」や「レシピ提案AI」を利用するには、Google AI Studioで無料発行できるGeminiのAPIキーが必要です。以下の手順に従って取得し、下の入力欄に保存してください。

APIキーの取得ステップ

  1. Google AI Studio にアクセスし、Googleアカウントでログインします。
  2. 画面左側（または右上）にある「APIキーを取得 (Get API key)」または「APIキーを作成 (Create API key)」という青いボタンをクリックします。
  3. 「既存のプロジェクトを選択 (Create API key in an existing project)」、または「+プロジェクトの作成」を選び、任意の名前を設定します。

    ⚠️ ※「プロジェクトの上限エラー」が出る場合は、新規作成ではなく、リストにある「既存のプロジェクト」をどれか一つ選択してください。

  4. 「キーを作成 (Create API key)」をクリックします。
  5. 生成された「キーをコピー (Copy)」をクリックして取得完了です。

アプリへの登録方法

1. コピーしたキーを、下記の「APIキー入力欄」に貼り付けます。
2. 「保存する」ボタンをクリックすれば設定完了です。

🥦 冷蔵庫管理アプリ

1
カメラで冷蔵庫の食材を撮影 →「✨ Geminiで解析する」を押す
📝 うまく撮れない場合は「手入力」タブで食材を追加
🗓 購入日の入力は必須・店舗名は任意で入力できます
⚠️ 登録されていない食材は日持ち日数を自分で入力してください
2
✂️ ボタンを押すと食材をカットした状態に切り替わり、期限が短くなります
3
「−」ボタンで食材の個数を1つずつ減らせます

1
